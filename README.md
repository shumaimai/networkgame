# ネットワーク屋さん

ネットワークの構築を、遊びながら学ぶ2Dゲームです。お客様の依頼どおりに機器を机に並べ、LANケーブルでつなぎ、設定して納品します。

## 遊び方
- **研修**(3件、スキップ可): スイッチとIPアドレス、ルーターとインターネット、故障の直し方を一手ずつ案内します。
- **受注ボード**: 自動生成された依頼が毎週5件並びます。構築とトラブル対応があり、難易度(★1〜5)と点数の内訳を見て選べます。
- **検収テスト**: 依頼ごとにテストが作られ、すべて合格すると納品できます。
- **チャレンジモード**: 受注時にオンにすると納期が付き、間に合えば報酬と経験値が増えます。
- **ヘルプ**: 方針、原因、答えの3段階。使うと報酬が減ります。辞書は無料です。
- **レベル**: 納品で経験値が入り、レベルが上がると機材・辞書・依頼の内容が増えます(Lv.13 まで)。
- **仕入れと倉庫**: 機材の相場は週ごとに定価の0.5〜2倍で動きます。まとめ買い割引があり、倉庫を借りて在庫を持てます。

学べる内容: IPアドレスとサブネット、L2スイッチ、ルーターとNAT、DNS、DHCPとリレー、プロキシ、パケットフィルター、NAS、VLANとトランク、L3スイッチと経路、ファイアウォールとDMZ、ポート転送、ループと冗長化、メール、無線LAN。

## 動かし方
Node.js が必要です。

    npm install
    npm run dev        # http://127.0.0.1:5173 をブラウザで開く
    npm run app        # デスクトップアプリとして起動
    npm run package    # release/NetworkShop-win32-x64/NetworkShop.exe を作る

## テスト
    npm run typecheck
    npm test           # シミュレータ、依頼の自動生成、ゲームの進行
    npm run e2e        # 画面の通しテスト(npm run dev を起動した状態で実行。Edge が必要)
