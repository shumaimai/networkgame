# ネットワーク屋さん

ネットワークの構築を、遊びながら学ぶ2Dゲームです。お客様の依頼どおりに機器を机に並べ、LANケーブルでつなぎ、設定して納品します。

## 遊び方
- **研修**(3件、スキップ可): スイッチとIPアドレス、ルーターとインターネット、故障の直し方を一手ずつ案内します。
- **受注**: 自動生成された依頼が毎週5件並びます。構築、トラブル対応、構成変更(Lv.19〜。動いているネットワークを作り替える)があり、難易度(★1〜5)と点数の内訳を見て選べます。
- **検収テスト**: 依頼ごとにテストが作られ、すべて合格すると納品できます。
- **ハードモード**: 受注時にオンにすると納期が付きます。間に合うと契約金が30%増え、経験値は続けて間に合った回数に応じて1.5倍〜8倍になります。遅れるか取り下げると、連続は0に戻ります。オフなら時間の制限はありません。
- **プレイグラウンド**: 設定からいつでも開ける、お金も依頼もない机です。作中の機器をレベルに関係なく何台でも置いて、自由に組んで試せます。
- **ヘルプ**: 方針、原因、答えの3段階。使うと契約金が減ります。ガイドは無料です。
- **ガイド**: 50項目。設定欄の「?」や依頼のタグから該当の項目を開けます。キーワードでも探せます。
- **机の拡大と移動**: 机の下のボタンかマウスのホイールで拡大・縮小し、何もない場所をドラッグして動かせます。机は最初に見えている範囲より広く、外側にも機器を置けます。
- **故障テスト**: 機器を一時的に止めて、残りの機器だけで通信できるかを自分で確かめられます(Lv.12〜)。
- **常連の依頼**: 研修1で納品したネットワークが、そのままの形で増設の依頼として戻ってきます。
- **レベル**: 納品で経験値が入り、レベルが上がると機材・ガイド・依頼の内容が増えます(Lv.24 まで)。
- **仕入れと倉庫**: 機材の相場は週ごとに定価の0.5〜2倍で動きます。まとめ買い割引があります。倉庫はスロット単位で借り、在庫を置けます。受注・仕入れ・倉庫は別々の画面です。

学べる内容: IPアドレスとサブネット、L2スイッチ、ルーターとNAT、DNS、DHCPとリレー、プロキシ、パケットフィルター、NAS、VLANとトランク、L3スイッチと経路、ファイアウォールとDMZ、ポート転送、ループと冗長化、メール、無線LAN、VPN、公開DNS(A・MX・TXT)、HTTPSの証明書、SPF、負荷分散、リバースプロキシ、ワイルドカード証明書とTLSの終端、DKIMとDMARC、プロキシの例外、広域イーサネットによる拠点間接続、回線の複数契約、拠点間VPN、ゲートウェイの冗長化(VRRP)、DHCPの二重化、クラウドと仮想サーバー、クラウドへの移行、監視、L3スイッチの二重化。

## 動かし方
Node.js が必要です。

    npm install
    npm run dev        # http://127.0.0.1:5173 をブラウザで開く
    npm run app        # デスクトップアプリとして起動
    npm run package    # release/NetworkShop-win32-x64/NetworkShop.exe を作る

## テスト
    npm run typecheck
    npm test           # シミュレータ、依頼の自動生成、ゲームの進行
    npm run e2e        # 画面の通しテスト(npm run dev を起動した状態で実行。Edge が必要)
    node e2e/adv.mjs   # Lv.17 以降の依頼を、種類ごとに1件ずつ画面の操作で組んで納品する
